UniChope Source on GitHub

Book a consultation without the email chain.

UniChope is a desktop app where students pick an open slot with a tutor, tutors set when they are available, and administrators keep modules and users in order.

Download UniChope.jar How to run it

Students

Browse consultation slots, book a session, and cancel a booking if plans change.

Tutors

Set your consultation availability and manage the bookings students make.

Administrators

Manage users, modules and tutor assignments, and view booking statistics.

Download and run

  1. Install Java 25.
  2. Download UniChope.jar from the latest release.
  3. Open a terminal in a writable folder and run: 
    java -jar UniChope.jar

JavaFX and all other dependencies are bundled. You do not need Gradle.

Your data is saved in data/unichope.db, relative to the folder you launch from. Keep that file to keep your data.
